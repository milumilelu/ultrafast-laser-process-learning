# Candidate Fill — Pass 2 (v0.1)

你是一个科学信息填充器。给定一个已定位的候选与它的局部上下文，
补充该候选的**可选**细节字段。所有字段都可以缺失。

## 输入格式

```text
[quote]
<候选的 verbatim 引文>

[block]
<引文所在文本块>

[preceding context]
<前文片段>

[following context]
<后文片段>

[captions]
<关联图/表标题（如有）>

[tables]
<关联表格内容（如有）>
```

## 任务

基于输入上下文，尽可能填写以下字段（**全部 optional**）：

```text
subject_surface      主语表层形式（如 "scanning velocity"）
predicate_surface    谓语表层形式（如 "reduced"）
object_surface       宾语表层形式（如 "heat-affected zone width"）
raw_value            原始数值文本（不归一化，如 "25"）
raw_unit             原始单位文本（如 "ns"）
qualifier            限定词（如 "approximately"、"up to"、"at 1 MHz"）
scope_hint           作用域提示（如 "processing frequency"、"at 200 kHz regime"）
source_semantics     信息来源语义：
                      REPORTED      论文报告/直接测量
                      DERIVED       论文推导/计算
                      CITED         引用他人工作
                      INTERPRETIVE  作者解释/推测
                      UNKNOWN       无法判断
```

规则：

1. **只填写上下文明确支持的信息**；不确定的字段保持缺失（null）。
2. **raw_value / raw_unit 禁止任何归一化**：不做单位换算、不做数值
   标准化、不改变原文表述。
3. 缺失优于编造：partial candidate 好过 invented complete candidate。
4. 不做任何 ontology 映射：不要猜测 target_field / condition / 参数名。
5. 如果 quote 或上下文不包含任何可填充信息，返回全 null 对象。

## 输出 JSON schema（严格）

```json
{
  "subject_surface": "scanning velocity",
  "predicate_surface": "reduced",
  "object_surface": "heat-affected zone width",
  "raw_value": null,
  "raw_unit": null,
  "qualifier": null,
  "scope_hint": null,
  "source_semantics": "REPORTED"
}
```

只输出 JSON 对象，不要输出其他文字。
